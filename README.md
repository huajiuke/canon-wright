# Canon Wright

把**阅读与写作**拧成同一条循环的个人小说创作工作台。

写作中暴露的知识缺口驱动阅读，读到的原文沉淀为卡片、并入 **canon**（故事圣经），最终写回正文。

```
灵感 ─┐
      ├→ 缺口 → 阅读任务 → 原文阅读 → 卡片 → canon → 章节正文 → 回检 → 新缺口/新灵感
章节 ─┘
```

## 三条不妥协的原则

1. **AI 只做检索与定位，不做取舍。** 读什么本身是创作行为，不能让渡给模型。
2. **原文是资产，摘要是索引。** 知识卡必须保留原文片段与出处，严禁用摘要替代原文。
3. **写作时不打扰。** 缺口探测异步进行，章末才结算交付。
